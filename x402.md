# x402 Payments

8k4 supports [x402](https://x402.org) — an HTTP payment protocol that lets agents pay for API queries with on-chain micropayments. No signup, no API key. The payment is the credential.

## How It Works

1. **Request** — Agent sends a normal API request to a paid endpoint.
2. **402 Response** — Server responds with `402 Payment Required` and a payment manifest.
3. **Payment** — Agent completes a $0.001 USDC payment on Base.
4. **Retry** — Agent retries the request with a payment proof header.
5. **Response** — Server verifies payment, returns data.

x402-capable HTTP clients handle steps 2–4 automatically.

## Payment Details

| Parameter | Value |
|-----------|-------|
| Network | Base (chain ID 8453) |
| Token | USDC |
| Amount | $0.001 per query |
| Payment address | Returned in the 402 manifest (`payTo` field) |

## Payment Manifest

When you hit a paid endpoint without auth, the API returns:

```json
{
  "payTo": "0x...",
  "amount": "1000",
  "currency": "USDC",
  "network": "base",
  "deadline": 1709384400
}
```

- `amount` is in USDC smallest units (1000 = $0.001)
- `deadline` is a unix timestamp — complete payment before this time

## curl Example

```bash
# Step 1: Make the request (returns 402 with payment manifest)
curl -i https://api.8k4protocol.com/agents/21480/score?chain=base

# Step 2: After completing USDC payment on Base, retry with proof
curl -H "X-Payment-Proof: 0x<transaction_hash>" \
  https://api.8k4protocol.com/agents/21480/score?chain=base
```

## Python Example

```python
import requests

API = "https://api.8k4protocol.com"

# First request — gets 402 with payment manifest
resp = requests.get(f"{API}/agents/21480/score?chain=base")

if resp.status_code == 402:
    manifest = resp.json()
    # manifest contains: payTo, amount, currency, network, deadline

    # Complete USDC payment on Base using your web3 library
    # (web3.py, eth_account, etc.)
    tx_hash = pay_usdc_on_base(
        to=manifest["payTo"],
        amount=int(manifest["amount"]),
        deadline=manifest["deadline"]
    )

    # Retry with payment proof
    resp = requests.get(
        f"{API}/agents/21480/score?chain=base",
        headers={"X-Payment-Proof": tx_hash}
    )

score_data = resp.json()
print(f"IGGY-Score: {score_data['score']}")
```

## Which Endpoints Require Payment?

| Endpoint | x402 Required |
|----------|---------------|
| `GET /health` | No — always free |
| `GET /agents/top` | No — free tier |
| `GET /agents/{id}/score` | Yes |
| `GET /wallet/{wallet}/score` | Yes |
| `GET /identity/{global_id}` | Yes |
| `GET /stats` | Yes |

API key holders bypass x402 entirely. If you include a valid `X-API-Key` header, no payment is required.

## Why x402?

Agents with on-chain wallets can pay for trust queries autonomously — no human in the loop, no payment processor, no subscription management. The payment happens on the same infrastructure the agent is already registered on.
