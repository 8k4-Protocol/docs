# x402 Payments

8k4 supports x402 for paid endpoints. You can call first, receive `402 Payment Required`, pay on Base (USDC), and retry.

## Typical flow

1. Request paid endpoint
2. Receive `402` payment challenge
3. Pay via x402 client/wallet flow
4. Retry automatically (or manually with proof)

## Example

```bash
curl -i "https://api.8k4protocol.com/agents/21480/score?chain=base"
# -> 402 Payment Required
```

Use an x402-capable client for automatic handling.

## Free + optional key coexistence

- `GET /agents/top` is open/public
- Paid scoring endpoints can be accessed via x402
- API keys are optional and self-serve via `POST /keys/generate`

## Why use key vs x402?

- Use **x402** for wallet-native pay-per-call flows
- Use **API key** for simpler server-side quota management (`/keys/info`, daily caps)
