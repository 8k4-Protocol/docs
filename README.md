# 8k4 Protocol Documentation

8k4 provides trust scoring + metadata infrastructure for ERC-8004 agents across Ethereum, Base, and BSC.

Auth model is now:
- open/public endpoints,
- x402 for paid calls,
- optional self-serve API keys (`POST /keys/generate`).
